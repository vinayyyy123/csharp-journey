## Key Learning

Operators are symbols used to perform calculations.

```text
+  Addition
-  Subtraction
*  Multiplication
/  Division
%  Remainder (Modulus)
```

---

## Simple Example

```csharp
int number1 = 10;
int number2 = 20;

int additionResult = number1 + number2;

Console.WriteLine("Result : " + additionResult);
```

### Output

```text
Result : 30
```

## Result Variables

Store calculations in a variable.

```csharp
int result = number1 + number2;
```

Benefits:

- Makes code easier to read
- Reuse results later
- Easier to debug
- Common practice in real projects

---

## Student Marks Example

```csharp
int maths = 80;
int science = 90;
int english = 70;

int totalMarks = maths + science + english;

Console.WriteLine("Total : " + totalMarks);
```

### Output

```text
Total : 240
```
