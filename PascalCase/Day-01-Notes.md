# Day 01 - Console Basics Notes

| Topic | Easy Memory Note |

| Console Application | A program that runs in a command window (console). |
| Program.cs | The starting file of a C# application. |
| Namespace | A container used to organize classes. |
| Class | A blueprint/container that holds code and data. |
| Main Method | The entry point where program execution starts. |
| Statement | A single instruction given to the computer. |
| Comments | Notes for developers that are ignored by the compiler. |
