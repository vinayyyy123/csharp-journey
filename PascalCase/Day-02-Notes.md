# Day 02 - Variables

## What is a Variable?

A variable is a container used to store data in memory.

It allows us to store information once and use it multiple times throughout a program.

---

## Why Use Variables?

- Store data for later use
- Reuse values without repeating them
- Make code easier to read and maintain
- Update values whenever required
- Reduce hardcoded data in programs

---

int age = 24;
